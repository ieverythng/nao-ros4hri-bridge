Planner Grounding + MoE Ownership Contract

Date: 2026-06-01 · Scope: planner seams, grounded context ownership, AB specialization boundaries.

Goal

Formalize grounded-context flow through planner seams without blurring ownership between chatbot_llm, planner_llm, nao_orchestrator, and AB=1 skills.

Contract Decisions

  1. /planner/request remains the grounding ingress seam with compact T0 context: knowledge_snapshot, scene_summary, state_t0.
  2. Planner egress should stay plan-centric; grounded payloads are transitional and should converge to a lightweight context_ref.
  3. AB=1 skills own live world-state resolution at execution time from AB=0 seams (/scene/summary, /kb/query, tracked-person feeds, skill-local checks).

ROS4HRI Ownership Alignment

chatbot_llm: grounding assembly
planner_llm: task decomposition
nao_orchestrator: deterministic dispatch
AB=1 skills: live evidence resolution

Planner context is advisory T0 evidence, not execution-time truth. This preserves node ownership while retaining enough context for planning pre/postconditions.

MoE-by-AB Practical Pattern

  1. Planner chooses AB=1 skills and emits compact targets (scene_targets, step args).
  2. AB=1 skills resolve live evidence from AB=0 sources at execution time.
  3. Execution feedback publishes typed evidence and status.
  4. Replanning uses fresh ingress context plus feedback, not stale output copies.

Architectural Guardrails

  • dialogue_manager owns dialogue lifecycle and speaking.
  • chatbot_llm owns user-facing LLM dialogue, routing, grounded projection, and planner ingress, not plans.
  • planner_llm owns planning, supervision, replan policy, and planner dialogue acts, not execution or speech.
  • nao_orchestrator owns admission, deterministic validation, dispatch, lineage, feedback, and dialogue relay, not LLM policy.
  • kb_skills owns KnowledgeCore transport; nao_scene_grounding owns detector normalization and scene summaries.
  • Runtime skills own fresh execution-time evidence.
  • Prompt changes require prospective SkillOpt baseline and holdout records.
  • Nested/upstream packages receive seam-focused changes only.

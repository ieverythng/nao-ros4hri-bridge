Grouped Delivery

The preloaded grouped-delivery sweep still accumulates stale spatial facts. Cup and book entities retain kitchen predicates while gaining recipient predicates. The recipient also gains object-like inverse relations such as placeOf. This is a post-effect contract problem, not a wording-only issue.

Launch Lesson

Runtime parameter changes are not enough for scored model ablations. A later log still showed LLM_REQUEST | stage=response model=qwen36-turbo-hermes after chatbot params were changed to the lab model. Scored runs must launch with explicit role arguments.

chatbot_model:=<model>
chatbot_intent_model:=<model>
chatbot_server_url:=<chat-completions-url>
planner_llm_model:=<model>
planner_llm_base_url:=<base-url>

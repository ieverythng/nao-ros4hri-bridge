# nao-ros4hri-bridge Wiki

This directory is the tracked Markdown surface for the repo wiki generated by GitNexus.

Refresh it with either:

```bash
tools/knowledge/generate_wiki.sh
tools/knowledge/gitnexus.sh wiki ...
```

The generated HTML viewer stays in `.gitnexus/wiki/`, while the Markdown pages synced here are the stable handoff surface for Codex, Cursor, and repo reviewers.

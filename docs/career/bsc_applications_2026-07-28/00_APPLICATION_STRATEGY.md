scientific modelling, and practical agentic AI engineering. His experience is
not limited to prompt authoring. At Aily Labs, the work forms a capability
cycle: MCP tools become gated skills; semantic table descriptions give an SQL

structured planning, skill execution, feedback, and controlled embodied-agent
evaluation.

  prototype. Its H0 contract proof explores task-scoped capability projection,

  externally validated.

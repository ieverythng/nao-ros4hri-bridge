# Academic CV

Editable source and renderer for Juan David Bendek Williamson's research-focused
academic curriculum vitae.

## Render

From the repository root:

```bash
/home/juanbeck/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3 \
  docs/career/academic_cv_2026-08-30/render_academic_cv.py
```

The final PDF is written to:

```text
output/pdf/Juan_Bendek_Academic_CV.pdf
```

## Scope

- Formal research and thesis work remains under `RESEARCH EXPERIENCE`.
- iTrader is labelled as independent, ongoing, and unpublished research and
  development.
- Aily Labs and ABS Consulting remain under `RELEVANT TECHNICAL EXPERIENCE`.
- Gamma is explicitly classified as a collaborative technical product project,
  not academic research.
- The 2023 PINN entry is limited to literature analysis, architecture, and
  pseudocode; it does not claim a completed implementation or benchmark.

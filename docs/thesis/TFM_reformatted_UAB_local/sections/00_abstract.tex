\markboth{Abstract}{Abstract}

Large language models have shown strong potential for instruction understanding and high-level reasoning in human-robot interaction. Their integration into a robot nevertheless requires more than a planner call: dialogue state, symbolic grounding, capability descriptions, execution admission, robot-facing skills, feedback, and user-facing reporting must remain coherent across a distributed runtime. This thesis presents a modular LLM-based interactive architecture and evaluates its implementation on the NAO robot.

The system separates dialogue management, semantic routing, symbolic grounding, task planning, deterministic orchestration, and skill execution. A chatbot interprets each turn and selects a conversational, knowledge, or execution route. A planner generates structured plans over a reviewed skill registry, while an orchestrator admits requests, validates plans, dispatches real or simulated skills, and returns typed execution feedback. A knowledge and perception path provides compact grounded context without allowing planning-time state to stand in for execution evidence.

The contribution is an inspectable interactive architecture and a validation method for its principal boundaries. The validation follows complete user turns together with focused planner, skill-execution, and controlled failure tests. It examines route correctness, plan validity, entity and role preservation, action order, symbolic postconditions, failure handling, and user-facing reporting.

The final evidence package contains 108 case records from 33 retained structured traces. The frozen primary configuration produced 64 passes and eight failures across 72 records. The twenty-two-case end-to-end questionnaire produced twenty passes and two failures. Controlled beginning- and middle-stage skill failures were recovered through versioned replanning, while incomplete capability-extreme plans were rejected before execution. Residual errors were concentrated in model-authored target selection, role preservation, clarification wording, and terminal closure.

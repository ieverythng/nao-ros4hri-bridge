# Reformatted TFM Overleaf Project

This ZIP was rebuilt from the uploaded TFM draft and the supplied UAB thesis skeleton.

Main changes:
- Converted the project from an `article` layout to the UAB-style `report` layout.
- Added UAB-style cover page, roman front matter, table of contents, list of figures, list of tables, and abbreviations.
- Split the thesis into `sections/*.tex` files for Overleaf editing.
- Replaced the previous placeholder validation/results sections with a fuller validation methodology, fake-skill scenario matrix, runtime questionnaire, preliminary results matrix, and action-level fake-skill results.
- Renamed `references.bib` to `bibliography.bib` and removed duplicate BibTeX entries.

Compile on Overleaf with pdfLaTeX + Biber.
